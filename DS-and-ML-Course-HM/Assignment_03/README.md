# Python Programming Master Class

A collection of Python programs, exercises, mini-projects, and practical assignments created while learning Python programming fundamentals. This repository covers core Python concepts from beginner to intermediate level, including data structures, functions, object-oriented programming, file handling, exception handling, and mini-project development.

### Python Basics

- Conditional Statements
- Loops

### Data Structures
- Lists
- Dictionaries
- Sets
- String Manipulation

### Functions & Modules
- Creating Functions
- Function Parameters
- Return Values
- Custom Modules

### Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors (`__init__`)
- Inheritance
- Polymorphism

### File Handling
- Reading Files
- Writing Files
- Working with Text Files
- Working with JSON Files

### Error & Exception Handling
- Try-Except Blocks

- Error Logging

### Mini Projects
- Authentication System
